## About Me

I'm a **DevOps & Cloud Engineer** based in Lahore, Pakistan, focused on making software delivery boring — in the best way. I containerize workloads, wire up infrastructure-as-code, and build CI/CD pipelines that turn a `git push` into a safe, repeatable deploy.

My work spans **AWS** and **GCP**, orchestrated with **Kubernetes** and provisioned with **Terraform**. I also come from a software engineering background — building backends with **Django** / **FastAPI**, REST APIs, and **React** front-ends.

🌱 Currently exploring: **Ansible** · **Prometheus** · **Grafana** — leveling up automation & observability.
